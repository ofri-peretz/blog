# Maintain reviews

One file per review, `NNN-YYYY-MM-DD.md`, from
[`review.template.md`](./review.template.md).

## Trigger

**1,000 blog sessions since the last review, or 30 days — whichever lands
first.** At current volume (~145 readers/month) the session threshold will not
fire before the 30-day cap, so in practice the date binds and the session count
only starts governing if traffic grows by roughly an order of magnitude. That is
stated here rather than discovered later.

improvised — that was the whole point of writing it before the stakes are high.

## Rules that outrank convenience

- Every figure over the [population rule](../analysis-population.md), never raw.
- Predictions written before numbers are read (§0 of the template).
- Counts, not rates.
- The review names at least one thing it could not determine.
- "Nothing learned yet, extend the window" is a valid outcome.
- The output is committed. A review that lives in a chat log did not happen.
